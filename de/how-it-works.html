Vollständiger Workflow

Wie Daten durch IrrigTech fließen

Jede Datenquelle im Feld speist dieselbe Pipeline, sodass ein Drohnenscan und ein Bodenmesswert auf derselben Karte landen.

01

Feld

Drohnenscans, Feldknoten und Bewässerungssensoren erfassen alle dasselbe physische Feld.

→
02

Datenerfassung

Bildmaterial, Bodenmesswerte sowie Durchfluss-/Druckdaten werden erfasst und geotaggt.

→
03

Übertragung

LoRa, WiFi oder Mobilfunk übertragen die Daten zurück — mit Store-and-Forward-Synchronisation bei eingeschränktem Signal.

→
04

IrrigTech Cloud

Messwerte und Bildmaterial werden dem richtigen Feld und Zeitstempel zugeordnet.

→
05

KI-gestützte Analyse

In Entwicklung

Modelle markieren Anomalien und Muster, die einen genaueren Blick verdienen — Entscheidungsunterstützung, keine Diagnose.

→
06

Feldkarte / Dashboard

Ergebnisse werden über die Feldgrenze gelegt, damit Sie sehen, wo — nicht nur was.

→
07

Warnmeldungen

Von Ihnen je Kultur und Zone festgelegte Schwellenwerte entscheiden, was eine Benachrichtigung wert ist.

→
08

Feldbericht

Jeder Scan, jeder Messwert und jede Warnmeldung wird der dauerhaften Historie dieses Felds zugeordnet.

→
09

Ihre Maßnahme

Sie oder Ihr Agronom entscheiden über die nächsten Schritte — Prüfen, Bewässern oder Behandeln.

Feldscanner-Drohne Prototyp

Automatischer Scan-Workflow

Sobald eine Feldgrenze definiert ist, können wiederholte Scans nach Zeitplan ablaufen, ohne dass ein Pilot vor Ort sein muss.

01

Planung

Sie legen fest, wie oft ein Feld gescannt werden soll.

→
02

Missionserstellung

Eine Flugroute wird automatisch aus der gespeicherten Feldgrenze erzeugt.

→
03

Autonomer Scan

Die Drohne fliegt die Mission und kehrt nach Abschluss automatisch zurück.

→
04

Datenerfassung

RGB- sowie, je nach Ausstattung, multispektrale oder thermische Aufnahmen werden erfasst und geotaggt.

→
05

Synchronisation

Bildmaterial wird hochgeladen, sobald eine Verbindung zur IrrigTech Cloud verfügbar ist.

→
06

KI-gestützte Analyse

Bildmaterial wird auf Anomalien, Stressindikatoren und Veränderungen im Zeitverlauf hin verarbeitet.

→
07

Feldkarte

Eine geotaggte Karte hebt Bereiche hervor, die einen genaueren Blick wert sein könnten.

→
08

Warnmeldung

Signifikante Veränderungen seit dem letzten Scan können eine Benachrichtigung auslösen.

→
09

Historischer Vergleich

Jeder Scan wird im Feldbericht gespeichert, sodass sich Trends im Zeitverlauf abzeichnen.

Dieser Workflow beschreibt das Entwicklungsziel der Feldscanner-Drohne. Die automatische Missionserstellung und die KI-gestützte Analyse befinden sich in Entwicklung — vor Maßnahmen in markierten Bereichen wird eine Überprüfung vor Ort empfohlen. Den aktuellen Status finden Sie unter Hardware.
