Process

From buried sensor to a decision you can act on

Five steps, running continuously, all season.

1

Install the nodes

Sensor nodes go in at root depth across each field — typically one per 0.5–1 hectare depending on soil variability.

2

Nodes report to the gateway

Every few minutes, each node radios its reading to the nearest gateway over LoRa, then up to the cloud.

3

The dashboard checks thresholds

Readings are compared against the targets you set per crop — a tomato field and a wheat field don't want the same NPK range.

4

You get alerted, or it self-corrects

A push notification goes to your phone — or, if automation is on, the dosing controller opens the right valve without anyone touching a tap.

5

You review the trend

Every reading is kept, so you can see what worked across a season, not just react to today's number.
